🤖 关于 PixelMimic

PixelMimic (像素拟人 / 桌面可视化自动化大师) v2.0

基于 Python 3.10+、PyWebView (Edge WebView2) 与 OpenCV 打造的现代化桌面可视化自动化操作工具。

🌟 零门槛积木化编排：像读故事一样看懂每一个操作步骤。

🎯 秒级截屏图像识别：OpenCV 模板匹配，多尺度高分屏自适应。

⚡ 全局热键保护：F7 全屏取样、F8 运行、F9 暂停、F10 紧急急停。
